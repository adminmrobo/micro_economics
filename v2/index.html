처음 오신 분께 — 이 과정을 3줄로

  1. 무엇을생산자(CH01~06) → 소비자(CH07~12) → 시장(CH13~16) → 일반균형(CH17~21) → 후생·정보(CH22~25) → 수학 부록(CH26~27)의 27장을 배우고, 묶음마다 점검 라운지에서 확인합니다.

1부 · 생산자 구역 (CH01~CH06)

CH01 · 기술CH01 기술 — 투입을 두 배로 하면 산출도 두 배일까사람과 장비를 모두 두 배로 늘리면 산출도 정확히 두 배가 될까?
  1. 한 요소만 늘리면 — 한계생산과 체감
  2. 모든 투입을 함께 늘리면 — 규모수익
  3. 같은 산출, 다른 조합 — 등량곡선과 기술적 대체율
  4. ⚔ 대결: 투입을 두 배로 늘릴 때, 비례 예측과 생산함수 계산 중 누가 정확할까?
CH02 · 이윤극대화CH02 이윤극대화 — 많이 넣기보다 남는 금액 계산하기늘 쓰던 투입 규칙을 버리고 가격에 맞춰 다시 고르면 얼마나 더 남을까? 손실이 나면 멈춰야 할까?
  1. 매출에서 지출 빼기 — 산출을 고르는 이윤
  2. 각 투입의 한계 가치 맞추기 — L* = (p/2w)²
  3. 손실과 중단은 같은 판단이 아니다
  4. ⚔ 대결: 늘 쓰던 공정(L = K = 1)과 가격에 맞춘 최적 투입, 고정비까지 뺀 총이윤은 누가 클까?
CH03 · 이윤함수CH03 이윤함수 — 가격이 바뀌면 최대 이윤은 어떻게 움직일까산출가격이 두 배가 되면, 옛 공정을 그대로 쓸 때와 다시 고를 때 이윤은 얼마나 다를까?
  1. 가격마다 최대 이윤을 기록하기 — 이윤함수
  2. 기울기가 공급량 — 호텔링 보조정리
  3. 볼록성과 동차성 — 모든 가격이 두 배면
  4. ⚔ 대결: 산출가격이 4에서 8로 올랐다. 옛 공정 그대로와 새 가격에서 다시 고르기, 이윤은 누가 클까?
CH04 · 비용최소화CH04 비용최소화 — 같은 산출을 가장 싸게 만드는 배합반반 섞는 익숙한 규칙과 가격에 맞춘 배합, 같은 산출 6을 만드는 비용은 얼마나 다를까?
  1. 등비용선과 등량곡선이 닿는 곳
  2. 반반 규칙은 얼마나 비쌀까 — 비율 θ로 보는 손실
  3. 최소비용을 함수로 — 그리고 이윤극대화와 다시 만나기
  4. ⚔ 대결: 산출 6을 만드는 데, 반반 배합과 가격에 맞춘 배합 중 누가 더 쌀까?
CH05 · 비용함수CH05 비용함수 — 임금이 오르면 최소비용은 얼마나 오를까임금이 두 배가 됐을 때, 옛 배합을 그대로 쓰면 다시 고를 때보다 얼마나 더 낼까?
  1. 모든 요소가격이 t배면 비용도 t배 — 그리고 산출에 대해서는
  2. 임금 1원의 비용 효과 — 셰퍼드 보조정리와 오목성
  3. 장비를 바꿀 수 없을 때 — 단기비용 ≥ 장기비용
  4. ⚔ 대결: 임금이 2에서 4로 올랐다. 옛 배합을 그대로 쓸 때와 다시 고를 때, 비용은 누가 작을까?
CH06 · 쌍대성CH06 쌍대성 — 가격에 비친 이윤으로 기술을 되찾을 수 있을까공정이 세 개뿐인 기업의 이윤을 가격별로 알면, 그 기업이 무엇을 만들 수 있는지 다시 그릴 수 있을까?
  1. 공정 세 개의 이윤함수 — 가격마다 최선의 공정
  2. 가격이 그리는 직선 — 지지선으로 기술 되찾기
  3. 거울에 비치지 않는 것 — 볼록화와 (1, 2)
  4. ⚔ 대결: p = 4, w = 1.5에서, 산출이 가장 많은 공정과 이윤이 가장 큰 공정 중 누가 더 벌까?

CH07 · 효용극대화CH07 효용극대화 — 같은 예산, 두 가지 장바구니돈을 반씩 나누는 장바구니는 언제 가장 좋은 선택일까?

  1. 꼭 사야 할 양을 먼저 — 스톤-기어리 수요
  2. 소득이 늘면 비중은 변한다 — 엥겔 곡선, 로이 항등식

한 줄 핵심 모음

각 장 단계마다 맨 위에 둔 "가져갈 한 가지"를 모았어요.

CH01 기술
  1. 다른 투입을 고정하고 한 투입만 늘릴 때 추가로 얻는 산출이 한계생산이다. 지수 α가 1보다 작으면 한 사람 더 쓸 때의 추가 산출은 점점 줄어든다.
  2. 모든 투입을 t배로 늘리면 산출은 tα+β배가 된다. 한 요소의 한계생산이 체감해도 α + β > 1이면 규모수익은 증가할 수 있다.
  3. 같은 산출을 내는 투입 조합을 이은 것이 등량곡선이고, 그 기울기의 크기(MRTS = αK/(βL))는 노동 하나로 대신할 수 있는 자본의 양이다.
CH02 이윤극대화
  1. 가격수용 기업의 이윤은 pq − c(q) − F이다. 이 기술에서 최소 가변비용은 c(q) = aq², a = wr/(w + r)이고, 이윤이 가장 큰 산출은 p = 2aq에서 정해진다.
  2. 투입 하나를 조금 늘릴 때 늘어나는 매출(p × 한계생산)이 그 투입의 가격과 같아지는 곳이 최적이다. q = √L + √K에서 L* = (p/2w)², K* = (p/2r)².
  3. 매몰 고정비는 생산할 때나 멈출 때나 똑같이 내므로 조업 결정을 바꾸지 않는다. 회피 가능한 고정비 Fₐ가 있으면 고정비 전 이윤이 Fₐ 이상일 때만 생산한다.
CH03 이윤함수
  1. 이윤함수는 주어진 가격에서 얻을 수 있는 최대 이윤이다. q = √L + √K이면 π(p, w, r) = p²(1/w + 1/r)/4.
  2. 이윤함수를 산출가격으로 미분하면 최적 산출, 요소가격으로 미분하면 최적 요소수요에 음의 부호를 붙인 값이 된다(∂π/∂p = q*, ∂π/∂w = −L*).
  3. 이윤함수는 가격에 대해 볼록하고(옛 계획을 고집하는 것보다 다시 고르는 것이 낫다), 1차 동차이다(모든 가격을 t배 하면 최대 이윤도 t배, 최적 계획은 그대로).
CH04 비용최소화
  1. 같은 산출을 내는 배합 중 가장 싼 것은 등량곡선과 가장 낮은 등비용선이 접하는 점이다. 그 점에서 기술적 대체율 = 요소가격 비율(w/r).
  2. 노동 몫 비율 θ = √L/q로 쓰면 비용은 C(θ) = q²[wθ² + r(1 − θ)²]이고 θ* = r/(w + r)에서 최소다. 다른 θ를 쓰면 q²(w + r)(θ − θ*)²만큼 더 든다.
  3. 최소비용을 산출의 함수로 쓰면 비용함수 C(q) = aq², a = wr/(w + r)이다. 가격수용 기업이 p = MC(q) = 2aq로 산출을 고르면 CH02의 q*와 정확히 같다.
CH05 비용함수
  1. 비용함수는 요소가격에 대해 1차 동차이다. 모든 요소가격을 t배 하면 최소비용도 t배, 최적 배합은 그대로다. 이 기술에서는 산출에 대해 2차(C ∝ q²)다.
  2. 비용함수를 임금으로 미분하면 조건부 노동수요가 된다(∂C/∂w = Lᶜ). 옛 배합을 고정한 비용은 임금에 대해 직선이고, 비용함수는 그 직선 아래에서 접한다(오목성).
  3. 자본을 K̄로 고정하면 단기 최소비용은 Cₛ = w[max(0, q − √K̄)]² + rK̄이고, 항상 장기비용 이상이다. 둘은 K̄가 그 산출의 최적 자본일 때만 같다.
CH06 쌍대성
  1. 공정이 몇 개뿐이면 이윤함수는 각 공정 이윤 직선들의 위쪽 테두리다. π(p, w) = max{0, 4p − 2w, 5p − 6w}. 테두리가 꺾이는 가격에서 선택 공정이 바뀐다.
  2. 가격 (p, w)에서 최대 이윤 π를 알면, 모든 실행 가능한 공정은 직선 q = (π + wL)/p 아래에 있다. 여러 가격의 지지선 아래쪽을 모으면 기술의 바깥 경계가 된다.
  3. 이윤함수로 되찾은 기술은 원래 공정들의 볼록 껍질이다. A(0, 0)과 B(2, 4)의 중간 (1, 2)는 되찾은 그림에는 있지만, 공정을 나눠 쓸 수 없다면 실제로는 불가능하다.
CH07 효용극대화
  1. 예산선 위를 따라 움직이며 효용이 가장 큰 묶음을 고른다. u = xαy1−α이면 x에 소득의 α, y에 1 − α를 쓴다: x* = αm/pₓ, y* = (1 − α)m/p_y.
  2. 내부해에서는 무차별곡선의 기울기(MRS)와 예산선의 기울기(가격비)가 같다. 코브-더글러스에서 MRS = αy/((1−α)x). 완전대체 선호처럼 경계해가 나오면 접선조건이 성립하지 않을 수 있다.
  3. 효용 ū를 얻는 최소 지출은 e(p, ū) = ū·C(p), C(p) = (pₓ/α)α(p_y/(1 − α))1−α이고 간접효용은 V(p, m) = m/C(p)다. e(p, V(p, m)) = m: 두 문제가 같은 점을 준다.
CH08 선택
  1. 관측 i에서 묶음 j를 살 수 있었는지는 같은 가격 pⁱ로 묶음 j의 값을 매겨 그때 쓴 돈 Eᵢᵢ와 비교해야 안다. 다른 행(다른 가격)의 금액끼리 비교하면 물가 차이를 섞게 된다.
  2. xⁱ가 xʲ에 (연쇄로) 현시선호되는데, 관측 j에서 xⁱ가 엄격히 더 쌌다면(Eⱼᵢ < Eⱼⱼ) GARP 위반이다. 국소 비포화 선호의 효용극대화로는 설명할 수 없다.
  3. 알려진 효용극대화로 만든 자료는 GARP를 통과한다. 하지만 통과했다고 무차별곡선 전체를 알 수는 없다. 관측하지 않은 묶음 사이의 순서는 정해지지 않는다.
CH09 수요
  1. u = (x − γₓ)α(y − γ_y)1−α이면 생계 묶음을 먼저 사고 남은 여유소득 R을 코브-더글러스처럼 나눈다: x = γₓ + αR/p, y = γ_y + (1 − α)R/q. R ≤ 0이면 이 공식을 쓸 수 없다.
  2. x의 소득탄력성은 αm/(px)로, 생계량 때문에 1과 다르다(비동조성). 간접효용에서 수요를 되찾을 때는 로이 항등식 x = −V_p/V_m처럼 가격미분을 소득미분으로 나눠야 효용 눈금이 바뀌어도 같은 수요가 나온다.
  3. 보상수요의 가격반응 S = ∂x/∂p + x·∂x/∂m은 대칭이고 음의 준정부호다. 일반수요의 가격미분 J에는 소득효과가 섞여 있어 이 성질이 보장되지 않는다. 이 모형에서 S₁₁ = −α(1 − α)R/p².
CH10 소비자잉여
  1. 가격 하락의 이득을 CV = m − e(p¹, u⁰)(변경 가격에서 처음 효용 유지에 필요 없는 돈)와 EV = e(p⁰, u¹) − m(처음 가격에서 새 효용을 얻는 데 더 필요한 돈)으로 잰다. 기준 가격이 달라 두 값은 다르다.
  2. 일반수요곡선 아래 면적 CS = αm ln(p⁰/p¹)는 소득효과가 있으면 CV와 EV 사이의 근사값이다. 소득효과가 없는 준선형 선호에서만 세 값이 같다.
  3. 전체 변화 x¹ − x⁰는 처음 효용을 유지하는 보상선택 h¹까지의 대체효과(h¹ − x⁰)와 나머지 소득효과(x¹ − h¹)의 합이다. 예: 37.5 = 12.5 + 25.
CH11 불확실성
  1. 위험한 결과의 가치는 효용의 확률 평균(기대효용)이다. 그 기대효용과 같은 효용을 주는 확실한 금액이 확실성등가 CE이고, 효용이 오목하면 CE < E[W]이다.
  2. CRRA 효용에서 ρ는 상대위험회피도다. ρ가 클수록 CE가 작고 RP가 크다. 완전보험(손실 전액 보상)에 낼 수 있는 최대 보험료는 W − CE다.
  3. 보험료가 공정 보험료보다 비싸면(ℓ > 0) 위험회피자도 일부만 보장받는 것이 최선일 수 있다. 로그 효용에서 최적 보장률 c* = [paW − (1 − p)π(W − L)]/(aπ), π = (1 + ℓ)pL, a = L − π (0~1로 제한).
CH12 계량경제학
  1. 시장 자료의 가격과 거래량은 수요 Q = 100 − bP + u와 공급 Q = 20 + dP + gz + v가 함께 정한다. 균형 가격 P = (80 + u − v − gz)/(b + d)에 수요 충격 u가 들어 있어 가격과 u가 상관된다.
  2. OLS 기울기는 −b + (b + d)Cov(P, u)/Var(P)로 수렴한다. 수요 충격이 클수록 편의가 크고, 공급 쪽 변동(gz, v)이 클수록 편의가 작다. 표본을 늘려도 편의는 사라지지 않는다.
  3. 도구 z가 공급만 옮기면(배제조건 δ = 0) IV는 참 기울기로 수렴한다. z가 수요 충격에도 들어가면(δ ≠ 0) plim β_IV = −b + δ(b + d)/(δ − g)로 편의가 남는다. 1단계 F는 관련성의 강도일 뿐 배제조건을 증명하지 않는다.
CH13 경쟁시장
  1. 가격수용 기업은 P = MC가 되는 양을 생산한다. 가동 여부는 매몰 고정비가 아니라 P ≥ min AVC로 정한다. 적자여도 P > AVC이면 가동이 손실을 줄인다.
  2. N개 동일 기업의 공급을 수평으로 더해 Q = N(P − c)/k를 만들고 역수요 P = A − BQ와 풀면 P* = (kA + BNc)/(k + BN), q* = (A − c)/(k + BN)이다.
  3. 장기에는 기업이 진입·퇴출하고 고정비도 회피 가능하다. 동일 기술·요소가격 불변이면 P = min AC: qᴸ = √(2F/k), Pᴸ = c + √(2Fk). 기업 수는 시장 수요가 정한다.
CH14 독점
  1. 독점의 한계수입은 MR = P + Q·P′ < P다. 이윤은 MR = MC에서 최대: 역수요 A − BQ, MC = c + kQ이면 Qᴹ = (A − c)/(2B + k), Pᴹ = A − BQᴹ. 내부해에서 (P − MC)/P = 1/|ε|.
  2. 총잉여 TS(Q) = (A − c)Q − (B + k)Q²/2는 P = MC인 Qᴱ에서 최대이고 독점 사중손실은 TS(Qᴱ) − TS(Qᴹ)이다. 가격상한 P̄ < Pᴹ이면 공급량은 min{(A − P̄)/B, (P̄ − c)/k}로, 두 값이 같은 P̄ = (kA + Bc)/(k + B)에서 최대다.
  3. 재판매가 없고 시장을 구분할 수 있으면 활성 시장마다 MR = 공통 MC가 되게 판다. qᵢ = (aᵢ − MC)/(2bᵢ), MC = c + kΣqᵢ. 공통 비용 때문에 한 시장의 수요 변화가 다른 시장의 판매도 바꾼다.
CH15 게임이론
  1. 상대가 왼쪽을 확률 q로 고를 때, 행의 각 행동 기대보수를 비교해 큰 쪽이 최적반응이다. 동전 맞추기(맞으면 행 +1)에서 q > 1/2이면 "위"가 엄격히 낫고, q = 1/2일 때만 두 행동이 같다.
  2. 혼합균형에서 내 확률은 내 보수가 아니라 상대의 두 행동을 무차별하게 만드는 값이다. 행의 보수 A로 열의 확률 q*, 열의 보수 B로 행의 확률 r*를 구한다. 조정게임(대각 3, 2)은 순수균형 둘과 r = q = 2/5인 혼합균형을 가진다.
  3. 완전정보 진입 게임에서는 끝에서부터 거꾸로 풀어, 진입 후 싸움이 수용보다 손해면 "싸우겠다"는 위협은 믿을 수 없다. 기존기업이 강경형일 확률이 θ이면 진입 기대보수는 (1 − θ)e − θℓ이고 θ < e/(e + ℓ)일 때 진입한다.
CH16 과점
  1. 기업 i의 반응함수는 BRᵢ(qⱼ) = max{0, (a − c − bqⱼ)/(2b)}다. 두 반응곡선의 교점이 쿠르노 균형 q₁ = q₂ = (a − c)/(3b), P = (a + 2c)/3이다. 기업 수 n이 늘면 가격은 c로 간다.
  2. 선도기업이 수량을 먼저 확정하면 후발 반응을 대입해 q₁ = (a − c)/(2b), q₂ = (a − c)/(4b)를 고른다. 동질재 가격경쟁(베르트랑)은 P = c. 카르텔은 총량 (a − c)/(2b). 같은 수요·비용도 규칙에 따라 결과가 다르다.
  3. 협조 보수 C, 한 번 일탈 보수 D > C, 이후 영구 처벌 보수 P < C이면 협조가 유지될 조건은 C/(1 − δ) ≥ D + δP/(1 − δ), 즉 δ ≥ (D − C)/(D − P)다. 처벌 국면의 행동이 단계게임 균형이어야 위협이 믿을 만하다.
