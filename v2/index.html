한 줄 핵심 모음

각 장 단계마다 맨 위에 둔 "가져갈 한 가지"를 모았어요.

CH01 기술
  1. 다른 투입을 고정하고 한 투입만 늘릴 때 추가로 얻는 산출이 한계생산이다. 지수 α가 1보다 작으면 한 사람 더 쓸 때의 추가 산출은 점점 줄어든다.
  2. 모든 투입을 t배로 늘리면 산출은 tα+β배가 된다. 한 요소의 한계생산이 체감해도 α + β > 1이면 규모수익은 증가할 수 있다.
  3. 같은 산출을 내는 투입 조합을 이은 것이 등량곡선이고, 그 기울기의 크기(MRTS = αK/(βL))는 노동 하나로 대신할 수 있는 자본의 양이다.
CH02 이윤극대화
  1. 가격수용 기업의 이윤은 pq − c(q) − F이다. 이 기술에서 최소 가변비용은 c(q) = aq², a = wr/(w + r)이고, 이윤이 가장 큰 산출은 p = 2aq에서 정해진다.
  2. 투입 하나를 조금 늘릴 때 늘어나는 매출(p × 한계생산)이 그 투입의 가격과 같아지는 곳이 최적이다. q = √L + √K에서 L* = (p/2w)², K* = (p/2r)².
  3. 매몰 고정비는 생산할 때나 멈출 때나 똑같이 내므로 조업 결정을 바꾸지 않는다. 회피 가능한 고정비 Fₐ가 있으면 고정비 전 이윤이 Fₐ 이상일 때만 생산한다.
CH03 이윤함수
  1. 이윤함수는 주어진 가격에서 얻을 수 있는 최대 이윤이다. q = √L + √K이면 π(p, w, r) = p²(1/w + 1/r)/4.
  2. 이윤함수를 산출가격으로 미분하면 최적 산출, 요소가격으로 미분하면 최적 요소수요에 음의 부호를 붙인 값이 된다(∂π/∂p = q*, ∂π/∂w = −L*).
  3. 이윤함수는 가격에 대해 볼록하고(옛 계획을 고집하는 것보다 다시 고르는 것이 낫다), 1차 동차이다(모든 가격을 t배 하면 최대 이윤도 t배, 최적 계획은 그대로).
CH04 비용최소화
  1. 같은 산출을 내는 배합 중 가장 싼 것은 등량곡선과 가장 낮은 등비용선이 접하는 점이다. 그 점에서 기술적 대체율 = 요소가격 비율(w/r).
  2. 노동 몫 비율 θ = √L/q로 쓰면 비용은 C(θ) = q²[wθ² + r(1 − θ)²]이고 θ* = r/(w + r)에서 최소다. 다른 θ를 쓰면 q²(w + r)(θ − θ*)²만큼 더 든다.
  3. 최소비용을 산출의 함수로 쓰면 비용함수 C(q) = aq², a = wr/(w + r)이다. 가격수용 기업이 p = MC(q) = 2aq로 산출을 고르면 CH02의 q*와 정확히 같다.
CH05 비용함수
  1. 비용함수는 요소가격에 대해 1차 동차이다. 모든 요소가격을 t배 하면 최소비용도 t배, 최적 배합은 그대로다. 이 기술에서는 산출에 대해 2차(C ∝ q²)다.
  2. 비용함수를 임금으로 미분하면 조건부 노동수요가 된다(∂C/∂w = Lᶜ). 옛 배합을 고정한 비용은 임금에 대해 직선이고, 비용함수는 그 직선 아래에서 접한다(오목성).
  3. 자본을 K̄로 고정하면 단기 최소비용은 Cₛ = w[max(0, q − √K̄)]² + rK̄이고, 항상 장기비용 이상이다. 둘은 K̄가 그 산출의 최적 자본일 때만 같다.

  1. 공공재는 같은 G를 모두가 함께 쓰므로 한계지불의사를 수직으로 더한다. 효율 공급은 Σ MRSᵢ = MC: aᵢ ln(1 + G) 효용, 단위비용 c이면 G* = Σaᵢ/c − 1이다.
  2. 각자 다른 사람 기여를 주어진 것으로 보고 내면 gᵢ = max{0, aᵢ/c − 1 − Σ_{j≠i} gⱼ}이고, 결국 선호가 가장 큰 사람만 내서 G_N = max aᵢ/c − 1 < G*이다. 린달 가격 tᵢ = c·aᵢ/Σaⱼ을 매기면 모두가 같은 G*를 원한다.
  3. 프로젝트를 신고 합 Σbᵢ ≥ C일 때 실행하고, 각자 자기 때문에 다른 사람이 입는 기회비용 tᵢ = max{0, Σ_{j≠i}bⱼ − C} − d(Σ_{j≠i}bⱼ − C)를 내게 하면 정직한 신고가 약우월전략이다. 다만 비용을 다 회수하지 못할 수 있다.
CH24 외부성
  1. 음의 외부성이 있으면 사회적 한계비용 MSC = MPC + MD이다. 시장은 MB = MPC인 q_m을 고르지만 효율 수량은 MB = MSC인 q*다. MB = 20 − q, MPC = 4 + 0.5q, MD = dq이면 q_m = 16/1.5, q* = 16/(1.5 + d).
  2. 단위세 t를 매기면 생산자는 MB = MPC + t에서 q(t) = (16 − t)/1.5를 고른다. t* = MD(q*) = d·q*로 하면 q(t*) = q*가 된다. 세수는 정부와 민간 사이의 이전이라 순사회편익에서 빼지 않는다.
  3. 총량 q*의 거래 가능한 허가권은 같은 효율 수량을 이룬다(세금은 가격을, 허가권은 수량을 고정). 재산권이 명확하고 거래비용이 없으며 당사자가 협상할 수 있으면, 권리를 누가 갖든 협상으로 효율 수량 q*에 도달한다(코즈).
CH25 정보
  1. 정보가 없으면 기대비용은 min(c, 50p)다. 정확도 t의 예보를 받으면 베이즈 규칙으로 비 확률을 고치고 신호마다 더 싼 행동을 고른다. EVSI = 정보 없을 때 비용 − 정보 있을 때 기대비용 ≥ 0이고, 예보가 결정을 바꿀 때만 양수다.
  2. 가격이 U[10, 20]에서 나오고 한 번 알아보는 비용이 c면, 미리 n곳을 보고 최저가에 사는 기대총비용은 10 + 10/(n + 1) + nc다. 이를 최소화하면 n* ≈ √(10/c) − 1. 순차 탐색에서는 예약가격 R = 10 + √(20c) 아래 가격이 나오면 멈춘다.
  3. 노력 e를 볼 수 없고 산출 Y = e + ε만 보이면, 성과급 비율 b가 노력을 끌어낸다(IC: e = b/c). 대리인이 위험회피(r)라 성과급은 위험 프리미엄 rb²σ²/2를 낳는다. 고용주 이윤 b/c − b²/(2c) − rb²σ²/2를 최대로 하면 b* = 1/(1 + rcσ²).
CH26 수학
  1. 작은 변화 dx에 대해 df ≈ ∇f·dx다. 길이 1인 방향 d의 변화율은 ∇f·d이고 기울기 방향에서 가장 크다(|∇f|). f = √(xy)는 1차 동차라 오일러 정리 x f_x + y f_y = f가 성립한다.
  2. 대칭행렬 H의 방향별 곡률 q(d) = dᵀHd는 최솟값 λ_min, 최댓값 λ_max(고유값) 사이에 있다. 모든 고유값이 양수면 볼록, 음수면 오목, 섞이면 안장(부정부호)이다. 대각 원소가 모두 양수여도 안장일 수 있다.
  3. F(x, θ) = 0에서 F_x ≠ 0이면 x를 θ의 매끄러운 함수로 볼 수 있고 dx/dθ = −F_θ/F_x다. 예: F = x³ + x − θ = 0이면 θ = 10에서 x = 2, dx/dθ = 1/(3x² + 1) = 1/13. 가역성이 깨지는 점이나 경계가 바뀌는 점에서는 쓸 수 없다.
CH27 최적화
  1. 자원 제약이 묶이고 두 활동이 모두 양수면 KKT 정상성에서 두 한계편익이 공통 그림자가격 λ와 같다. a = 5, b = 3, ρ = 1/4, m = 4이면 x = [a − b + (1 − ρ)m]/[2(1 − ρ)] = 10/3, y = 2/3, λ = 3/2, 순편익 37/3.
  2. KKT: 가능성, 승수 부호(λ, μ ≥ 0), 정상성, 상보성 λ(m − x − y) = 0, μₓx = 0, μ_yy = 0. 무제약 포화점이 가능하면 자원을 남기고 λ = 0이다. a = b, 대칭이면 λ = a − m(1 + ρ)/2가 0이 되는 m = 2a/(1 + ρ)부터 포화.
  3. 최적값 V(m)을 자원으로 미분하면 승수 λ와 같다(포락정리). λ는 평균 편익 V/m이 아니라 한계값이다. 선택량의 반응 dx*/dm은 다른 질문으로, 묶인 내부에서는 각 1/2, 포화 후에는 0이다.
