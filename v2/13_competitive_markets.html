1기업 공급

가격 = 한계비용 — 그리고 적자여도 가동하는 이유

모형: 가격수용 기업 · 가동 조건일상: 적자 가게가 문을 여는 이유

가격 P를 바꾸며 기업의 MC·AVC·AC 곡선과 공급량을 봐요. 가격이 AC 아래인데 AVC 위인 구간에 주목합니다.

이 단계에서 가져갈 한 가지

가격수용 기업은 P = MC가 되는 양을 생산한다. 가동 여부는 매몰 고정비가 아니라 P ≥ min AVC로 정한다. 적자여도 P > AVC이면 가동이 손실을 줄인다.

왜 P = MC에서 생산해요?

학교 수학으로 보면 고등학교 이차함수 최댓값이에요. (P − c)q − kq²/2.

C(q) = F + cq + kq²/2 · MC = c + kq, AVC = c + kq/2, AC = F/q + c + kq/2 · q(P) = max{0, (P − c)/k}
F단기 매몰 고정비
c + kq한계비용 — 증가
AVC가동 판단의 기준
생산자잉여매출 − 가변비용
숫자로 한 번 해 보기c = 10, k = 2, F = 100, P = 25 → q = 15 ÷ 2 = 7.5생산자잉여 = 15 × 7.5 − 7.5² = 56.25이윤 = 56.25 − 100 = −43.75 > 멈출 때 −100AVC = 10 + 7.5 = 17.5 < 25 → 가동

2시장균형

기업 공급을 더해 수요와 만나기 — 단기 시장균형

모형: 시장 공급 = N·q(P)일상: 가게 수가 줄면 가격은?

기업 수 N을 바꾸며 시장 공급곡선과 수요곡선의 교점을 찾아요.

이 단계에서 가져갈 한 가지

N개 동일 기업의 공급을 수평으로 더해 Q = N(P − c)/k를 만들고 역수요 P = A − BQ와 풀면 P* = (kA + BNc)/(k + BN), q* = (A − c)/(k + BN)이다.

P* 공식은 어떻게 나와요?

학교 수학으로 보면 중학교 연립일차방정식이에요.

시장 공급: P = c + kQ/N · 수요: P = A − BQ → Q* = N(A − c)/(k + BN), P* = (kA + BNc)/(k + BN)
N기업 수
k/N시장 공급곡선의 기울기 — N이 클수록 완만
A, B수요 절편·기울기
A ≤ c거래 없음
숫자로 한 번 해 보기A = 100, B = 1, c = 10, k = 2, N = 10P* = (200 + 100) ÷ 12 = 25q* = 90 ÷ 12 = 7.5, Q* = 75N = 5 → P* = (200 + 50) ÷ 7 ≈ 35.7

자유진입과 퇴출 — 장기 가격은 최소 평균비용

모형: 장기 P = min AC일상: 장사가 잘되면 가게가 늘어난다

고정비 F를 바꾸며 평균비용 곡선의 바닥(효율적 규모)을 찾아요. 그 높이가 장기 가격이에요.

이 단계에서 가져갈 한 가지

장기에는 기업이 진입·퇴출하고 고정비도 회피 가능하다. 동일 기술·요소가격 불변이면 P = min AC: qᴸ = √(2F/k), Pᴸ = c + √(2Fk). 기업 수는 시장 수요가 정한다.

왜 이 방법을 쓰나

문제 상황

단기에는 적자예요. 장기에는 어떻게 될까요?

앞 방법의 한계

단기 균형은 기업 수를 고정해서 손실이 계속 남아요.

해법

손실이면 일부가 나가고, 남은 기업의 가격이 오르며, 이윤 0이 될 때 멈춰요.

쉽게 말하면 장사가 안되면 가게가 줄고, 남은 가게가 버틸 만해지면 더 줄지 않아요.

수식이 궁금하면 펼쳐 보기 — 수학 수식을 어려워하는 조수가 대신 물어봅니다

min AC는 어떻게 구해요?

학교 수학으로 보면 고등학교 F/q + kq/2의 최솟값이에요(산술·기하 평균).

AC = F/q + c + kq/2 · dAC/dq = −F/q² + k/2 = 0 → qᴸ = √(2F/k), Pᴸ = c + √(2Fk) · Qᴸ = (A − Pᴸ)/B, Nᴸ = Qᴸ/qᴸ
qᴸ효율적 규모(평균비용 최소)
Pᴸ장기 가격
Nᴸ장기 기업 수
수평 장기 공급일정비용 산업의 특수한 결과
숫자로 한 번 해 보기F = 100, k = 2 → qᴸ = √100 = 10Pᴸ = 10 + √400 = 30Qᴸ = 100 − 30 = 70, Nᴸ = 7단기 P = 25 < 30 → 기업 3곳 퇴출

열 곳 중 세 곳이 나가면 가격이 30이 되고 이윤이 0이 돼요. 그 규모가 10이고요.

그래프로 검증 — 평균비용이 가장 낮은 산출(효율적 규모)

위 수식 풀이에서 구한 답을 그래프에서 직접 찾아 같은지 확인해요. 조절기를 바꾸면 수식 답과 그래프 답이 함께 다시 계산됩니다.

일상으로 치면

떡볶이집이 잘되면 옆에 떡볶이집이 생기고, 안되면 문을 닫아요. 결국 "겨우 버틸 만한" 가격에서 멈춰요.

경제학으로는

장기 경쟁균형: P = MC = min AC, 이윤 0. 요소가격이 산업 규모에 따라 오르면(비용 증가 산업) 장기 공급은 우상향이에요. 기업마다 기술이 다르면 효율적인 기업은 지대를 얻어요.

방청석 X2예요. 코드를 받으면 실행해서 본문 숫자와 같은지 꼭 확인할게요!

1. 기업 공급과 시장균형 계산기
파이썬으로 비용 C(q) = F + c*q + k*q**2/2 의 기업 공급 q(P) = max(0, (P-c)/k) 와 N개 기업 시장 공급, 역수요 P = A - B*Q 의 균형을 sympy 로 푸는 코드를 짜 줘. A=100, B=1, c=10, k=2, F=100, N=10 에서 P=25, q=7.5, Q=75, 기업 이윤 -43.75 가 나오는지 assert 로 확인해 줘.
2. 장기균형과 기업 수
파이썬으로 AC(q) = F/q + c + k*q/2 를 scipy.optimize.minimize_scalar 로 최소화해 효율적 규모 q_L, 장기 가격 P_L, 장기 기업 수 N_L = (A-P_L)/B/q_L 을 계산하는 코드를 짜 줘. F 를 10~400 으로 바꾸며 P_L 과 N_L 을 그래프로 그리고, F=100 에서 (10, 30, 7) 인지 확인해 줘.
3. 단기→장기 조정 시뮬레이션
처음 N=10 에서 시작해 매 기간 기업 이윤이 양수면 기업 1개 진입, 음수면 1개 퇴출하는 규칙으로 30기간 시뮬레이션하는 파이썬 코드를 짜 줘. 기간별 가격·기업 수·기업 이윤을 그래프로 그리고 가격이 장기 가격 30 근처로 수렴하는지 보여 줘. 마지막에 결과가 본문 예시값과 맞는지 assert 로 확인해 줘.
