# 미시경제학 연구실

질문하고 → 조건을 바꿔 실험하고 → 계산으로 확인하는 미시경제학 학습 자료입니다.

- 사이트: https://adminmrobo.github.io/micro_economics/ (GitHub Pages)
- 글 · 안상선 ((주)M-Robo 대표) · [저자 소개](https://adminmrobo.github.io/who_am_i/who_am_i.html)

## 구성

| 폴더 | 내용 |
|---|---|
| `index.html` | 첫 화면 |
| `blog/` | 블로그 — 본편 8편(질문으로 읽는 미시경제학), 부록 27편(교과서와 함께 읽기), 두 축 대응표 |
| `v1/` | 버전1 · 내 노트 중심판 — 교과서 8장(CH0~CH07), 연구실 8개, 실전 연습장 |
| `v2/` | 버전2 · 교과서 동행판 — 교과서 27장, 연구실 27개, 실전 연습장 |
| `assets/chars/` | 캐릭터 픽셀아트(박사·조수 하루·초파리 연구원·Money-Robo) |

각 묶음의 마지막 장 `practice/index.html`은 공장·가게·보험사·거래소를 운영해 보는 시뮬레이터 동적 대시보드입니다. 주소 끝에 `#factory`, `#shop`, `#insurer`, `#exchange`를 붙이면 해당 장면이 바로 열립니다.

## 블로그 고치기

원고는 `blog/src/`의 마크다운입니다(`main-*.md` 본편, `app-*.md` 부록, `map.md` 대응표). 고친 뒤 저장소 루트에서 다시 빌드합니다.

```bash
pip install markdown
python3 blog/build.py
```

## 이용 안내

- 설치·서버 없이 브라우저에서 작동합니다. 외부 참고문헌을 열 때만 인터넷이 필요합니다.
- 실험 입력과 퀴즈 응답은 현재 탭에만 남고 외부로 보내지 않습니다.
- 수치는 교육용 예시이며 실제 추정치나 정책·투자 권고가 아닙니다.
- 버전2의 장 배열은 Hal R. Varian 『Microeconomic Analysis』 제3판을 따르지만, 해당 책의 본문·문제·증명을 옮기거나 대신하지 않습니다.
