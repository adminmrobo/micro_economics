학습 안내

학습 경로

CH0에서 모형과 수학적 사고를 익힌 뒤 CH01·CH02에서 소비자와 기업의 선택을 공부합니다. CH03·CH04는 시장과 전략, CH05는 여러 시장과 시간·위험의 연결을 다룹니다. CH06·CH07에서는 후생·정책·정보와 제도를 분석합니다.

일차·이차함수, 비율·로그, 기본적인 미분과 확률을 알고 있으면 실험을 활용하기 쉽습니다. 행렬·곡률·제약하 최적화는 수학과 최적화에서 설명합니다.

한 절을 공부하는 순서

  1. 학습목표를 확인하고 핵심 용어를 자신의 말로 정의합니다.
  2. 목적함수·제약·시장구조·정보 가정을 구분합니다.
  3. 유도 과정에서 사용한 조건을 표시하고 내점과 경계를 구별합니다.
  4. 기준을 저장한 뒤 한 변수씩 바꾸며 결과의 방향을 먼저 예측합니다.
  5. 확인 문제에 답하고 모형의 적용 범위를 설명합니다.

비교 실험 사용법

기준과 현재 결과를 같은 축에서 비교하세요. 입력·프리셋 변경은 저장 기준을 바꾸지 않습니다. ‘현재를 기준으로’는 출발점을 갱신하고 ‘초기화’는 처음 설정으로 돌아갑니다. 세부 기능은 실험 화면에 표시됩니다.

전체 변화가0이어도 서로 다른 효과가 상쇄되었을 수 있습니다. 대체·소득 효과, 수량·가격 효과를 나누어 읽으세요. 불가능한 예산이나 정의되지 않는 해는 상태 메시지로 표시됩니다.

숫자는 교육용 예시 또는 명시된 합성자료입니다. 모형의 결과를 실제 관측치나 정책·투자 권고로 해석하지 마세요.

파일 사용

ZIP 전체를 압축 해제하고 index.html을 여세요. 폴더 구조를 유지하면 설치·서버 없이 오프라인에서 작동합니다. 외부 참고문헌을 열 때만 인터넷이 필요합니다.

기준 저장은 브라우저가 허용하는 로컬 저장소에만 기록됩니다. 차단되어도 현재 탭에서 비교할 수 있으며 입력을 외부로 전송하지 않습니다. 모바일에서는 화면을 가로로 돌리면 넓은 표를 읽기 편합니다.
