## 공용 장비의 예약표

두 연구원이 장비를 번갈아 쓰기로 약속했습니다. 오늘 약속을 깨고 먼저 쓰면 실험을 더 할 수 있습니다. 하지만 상대는 다음부터 협조하지 않을 것입니다. 오늘의 이득은 미래의 협조를 포기할 만큼 클까요?

## 첫째 단계 · 한 번의 선택

이 관계의 보수를 이렇게 놓습니다.

- 둘 다 협조: 각자 C
- 나만 약속을 깸: 나는 D = C + g (g는 오늘의 추가 이득)
- 둘 다 약속을 깸: 각자 P = C − h (h는 협조가 깨질 때 잃는 몫)
- 나만 협조: S (가장 나쁨)

한 번만 만난다면 상대가 무엇을 하든 약속을 깨는 쪽이 낫습니다. 그래서 둘 다 깨고, 둘 다 협조했을 때보다 나빠집니다.

## 둘째 단계 · 미래를 같은 단위로

같은 상대를 계속 만난다면 이야기가 달라집니다. 다음 기간의 1점을 오늘의 δ점으로 보는 할인인자 δ(0과 1 사이)를 쓰면

- 계속 협조: C + δC + δ²C + … = **C / (1−δ)**
- 지금 깨고 처벌받음: D + δP + δ²P + … = **D + δP / (1−δ)**

입니다. 오늘 하루의 큰 보수와 긴 시간의 현재가치는 같은 말이 아닙니다.

## 셋째 단계 · 유인과 신뢰성

두 값을 비교하면 협조가 유리한 조건이 깔끔하게 나옵니다.

**δ ≥ g / (g + h)**

오늘의 유혹 g가 클수록, 협조가 깨질 때의 손실 h가 작을수록 더 큰 δ가 필요합니다. 미래를 충분히 중요하게 여겨야 약속이 지켜집니다.

여기에 한 가지 조건이 더 붙습니다. "깨면 다시는 협조하지 않겠다"는 위협이 **실제로 실행할 만해야** 합니다. 처벌 단계에서 서로 깨는 것이 각자에게 최선이어야 위협이 믿을 만해집니다.

## 이 모형이 말하지 않는 것

- 상대의 행동을 완전히 관찰할 수 있고, 관계가 끝없이 이어지며, 두 사람의 δ가 같다고 가정했습니다.
- 끝나는 날이 정해진 관계에 무한합 공식을 그대로 쓰면 안 됩니다.
- 판정은 한 사람의 할인 보수입니다. 어느 쪽이 도덕적으로 옳은지를 판단하지 않습니다.
