# 미시경제학 버전1_강화판

ZIP 전체를 압축 해제하고 `microeconomics-v1-enhanced/index.html`을 여세요.

- 연구실 목차: `index.html`
- 교과서 전체 목차: `textbook.html`
- 기존 교과서 8개 장과 모든 세부 학습 내용을 함께 제공합니다.
- 연구실 8개: `labs/lab00.html`부터 `labs/lab07.html`. 각 파일은 오프라인 단독 실행이 가능합니다.
- 각 연구실은 개념정리, 조건 실험, 계산 기반 선택 대결, 확인 문제, 용어 검색과 학습 꾸러미 내려받기를 제공합니다.
- 연구실 상태는 현재 탭에서만 유지됩니다. 기존 교과서 저장 기능은 각 페이지 설명을 따릅니다.
- JavaScript 실행이 가능한 브라우저를 사용하세요. 외부 참고문헌에는 인터넷 연결이 필요합니다.
