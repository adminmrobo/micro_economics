03 / 계산의 근거

그래프 뒤에서 계산되는 것

곡선을 임의로 움직이지 않습니다. 입력값이 바뀌면 아래 수식으로 선택점과 곡선을 다시 계산합니다.

설명용 Cobb–Douglas 모형

U(x,y) = xαy1−α

재화는 x, y ≥ 0. 가격·소득은 양수이고 0 < α < 1입니다. 이 조건에서 단조적이고 엄격히 볼록한 선호를 표현하며 유일한 내부 최적해를 얻습니다.

효용의 정규화: 효용을 U=x^αy^(1−α)로 두고 지출 비중 α를 조절합니다. α=½의 √(xy)는 xy와 같은 선호 순서를 표현하지만 효용의 숫자 척도는 다릅니다.

효용극대화 해

x* = αm / px
y* = (1−α)m / py

최적점에서 pₓx*=αm, pᵧy*=(1−α)m. 합하면 m이므로 예산을 모두 사용합니다.

기울기 크기 MRS = [α/(1−α)]·(y/x). 최적점에서는 가격비 pₓ/pᵧ와 같습니다.

지출함수와 Hicks 수요 수식 펼치기

e(px,py,ū) = ū / [(α/px)α((1−α)/py)1−α]

hx = αe / px,   hy = (1−α)e / py

최소지출 e를 두 재화에 각각 α와 1−α의 비중으로 배분합니다. 양의 목표 효용에서 U(hₓ,hᵧ)=ū, pₓhₓ+pᵧhᵧ=e입니다.

이 학습 예제이 다루지 않는 경우
완전대체재·완전보완재, 비볼록 선호, 모서리해, 이산 재화, 저축·차입, 가격변화의 Slutsky 분해, CV·EV는 이번 실험 범위 밖입니다. 접점이 없는 경우에도 최적해가 존재할 수 있으므로 이 단원의 접점 그림을 모든 소비자 문제에 일반화하지 마세요.

04 / 직접 확인

예측 → 조작 → 설명

기본값 m=120, pₓ=10, pᵧ=5, α=0.5에서 시작합니다. 답을 보기 전에 슬라이더를 조작해 확인해보세요.

QUESTION 01

x의 가격만 2배가 되면?

pₓ를 10에서 20으로 올립니다. x*와 y*는 어떻게 변할까요?

해설 보기
x*는 6→3, y*는 12로 유지됩니다. x에 쓰는 돈은 60으로 같지만 가격이 2배이므로 수량은 절반입니다. 이는 이 Cobb–Douglas 예제의 결과이지 모든 선호에서 y 수요가 고정된다는 뜻은 아닙니다.
QUESTION 02

소득만 2배가 되면?

소득 m을 120에서 240으로 올립니다. 예산선과 최적점은?

해설 보기
x*=12, y*=24로 모두 2배입니다. 가격비는 같아 예산선은 평행 이동합니다. 이 효용함수는 1차 동차이므로 표시되는 최대 효용도 2배가 됩니다.
QUESTION 03

두 문제의 답이 같아지는 순간

기본값으로 초기화한 뒤, 최대 효용을 목표 효용으로 맞춰보세요.

해설 보기
e=120, hₓ=6, hᵧ=12가 됩니다. ‘120으로 얻는 최대 효용’을 달성하는 최소 비용 역시 120입니다. 선호·가격을 같게 두고 두 문제를 연결한 결과입니다.

선택과 지출 문제의 연결

가격과 선호를 고정하면 효용극대화로 얻은 효용을 지출최소화의 목표로 사용할 수 있습니다. 이때 최소지출은 처음 소득과 같고 두 문제의 선택묶음도 일치합니다. 목표효용을 임의로 바꾸면 이 등식은 성립하지 않습니다.

최적조건의 유도

접선조건이 나오는 과정

초기부존 ω와 기업 이윤의 배당이 있으면 소득은 m=p·ω+Σθⱼπⱼ(p)처럼 가격에도 의존할 수 있습니다. 이 실험에서는 그 효과를 분리하기 위해 외생적 현금소득 m을 가정합니다.

ℒ=U(x,y)+λ(m−pₓx−pᵧy)
Uₓ=λpₓ, Uᵧ=λpᵧ, pₓx+pᵧy=m

양의 내부해에서 두 한계효용 조건을 나누면 MRS=Uₓ/Uᵧ=pₓ/pᵧ입니다. 한 단위 화폐의 추가 지출이 주는 효용을 두 재화에서 같게 하는 조건입니다. 무차별곡선 위의 전미분 dU=Uₓdx+Uᵧdy=0도 같은 접선 해석으로 연결됩니다.

Cobb–Douglas의 로그를 최대화하면 α/x=λpₓ, (1−α)/y=λpᵧ입니다. 각각 x,y를 곱하고 더하면 1=λm이므로 x*=αm/pₓ, y*=(1−α)m/pᵧ입니다. 로그 변환은 서수적 선택을 보존하지만 승수의 수치는 원래 효용 표현의 승수와 다릅니다.

최적조건의 충분성은 목적함수와 제약의 성질에 달려 있습니다. 여기서는 엄격히 오목한 로그 목적함수와 양의 가격·소득으로 해의 유일성을 검증합니다. 일반 효용의 FOC만으로 전역 최대를 보장하지 않으며 코너해에는 부등식 조건이 필요합니다.

핵심 정리와 확인

가격·선호를 고정한 상태에서 목표효용을 v(p,m)으로 놓으면 최소지출은 얼마인가?

해설 보기

국소 비포화성과 이 모형의 정칙조건 아래 e(p,v(p,m))=m입니다. 다른 목표효용이나 다른 가격을 대입한 경우에는 같은 등식을 사용할 수 없습니다.
